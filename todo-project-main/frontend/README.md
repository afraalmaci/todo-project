# Frontend

React app for the Todo Project. Bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

See the [root README](../README.md) for what this project is, how to run it locally, and how it's deployed.

## Available scripts

- `npm start` - runs the dev server at http://localhost:3000
- `npm test` - runs the test suite
- `npm run build` - creates a production build in `build/`
